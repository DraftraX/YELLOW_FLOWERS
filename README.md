# 🌻 Flores Amarillas — 21 de Septiembre (Para Maria Iboni <3)

Una experiencia interactiva y romántica de **Flores Amarillas**, diseñada con flores artesanales dinámicas, unboxing secuencial con regalo sorpresa, banda de animalitos interactivos y un sistema de doble enlace (instancia pública y panel de personalización).

Repositorio: [https://github.com/DraftraX/21-09.git](https://github.com/DraftraX/21-09.git)

---

## 🌟 Dos Instancias y Enlaces

El proyecto cuenta con dos modos independientes:

### 1. 🎁 Enlace Público (Vista de Regalo)
- **Archivo**: `index.html`
- **URL en GitHub Pages**: `https://draftrax.github.io/21-09/`
- **Experiencia**:
  - Al cargar, la destinataria (**Maria Iboni <3**) ve únicamente una misteriosa y brillante **caja de regalo** con su nombre en la etiqueta.
  - Al tocar la caja, el lazo y la tapa vuelan, ocurre una explosión de confeti dorado y pétalos, comienza una melodía romántica y **se revela en cascada todo el contenido**:
    1. Carta secreta de amor personalizada.
    2. El majestuoso **ramo de flores amarillas** (girasoles, rosas, tulipanes, margaritas y follaje con brisa interactiva, polen y destellos).
    3. Foto central con corona rotativa de girasoles.
    4. Notitas interactivas con las razones de amor.
    5. Banda de animalitos interactivos con globos de diálogo y reacciones cariñosas.
  - Es totalmente compatible con enlaces personalizados que llevan datos en el enlace (`#data=...`), sin requerir bases de datos externas.

### 2. ✏️ Enlace de Modificación (Taller / Editor)
- **Archivo**: `editor.html`
- **URL en GitHub Pages**: `https://draftrax.github.io/21-09/editor.html`
- **Características**:
  - **Destinataria & Carta**: Cambia el nombre (`Maria Iboni <3`), dedicatorias, firma y el cuerpo de la carta secreta.
  - **Foto & Multimedia**: Pega una URL o sube una foto desde tu dispositivo (se procesa al instante).
  - **Temáticas Visuales**: Cambia entre *Amarillo Radiante Clásico*, *Atardecer Dorado*, *Noche Mágica Estrellada* y *Jardín Floral Pastel*.
  - **Animalitos Amigos**: Activa/desactiva animalitos y edita sus frases de diálogo.
  - **Notitas**: Agrega, modifica o borra razones de amor.
  - **Música**: Personaliza con audio MP3 o usa el sintetizador de caja musical incorporado.
  - **Generador de Enlaces**: Botón de un clic para copiar el enlace público generado listo para enviar por WhatsApp, Instagram o mensaje.
  - **Vista previa en tiempo real**: Mira cómo queda cada cambio al instante antes de enviar el regalo.

## 🚀 Despliegue en GitHub Pages

Para publicar ambos enlaces en internet gratuitamente con GitHub Pages:

1. **Subir los cambios a GitHub**:
   ```bash
   git add .
   git commit -m "Flores Amarillas para Maria Iboni <3 con ramo dinámico y editor"
   git branch -M main
   git push -u origin main
   ```

2. **Activar GitHub Pages**:
   - En tu repositorio en GitHub, ve a **Settings** > **Pages**.
   - En **Source**, selecciona `Deploy from a branch`.
   - En **Branch**, selecciona `main` y la carpeta `/ (root)`.
   - Haz clic en **Save**.

En unos segundos estarán listos tus 2 enlaces:
- 🎁 **Regalo Público**: `https://draftrax.github.io/21-09/`
- ✏️ **Editor de Modificación**: `https://draftrax.github.io/21-09/editor.html`
